# Replicating "Refusal in LMs Is Mediated by a Single Direction"

Learning replication of Arditi et al. (2024), arXiv:2406.11717, on a small Qwen2.5 model with TransformerLens.

- `experiments/` : one script per roadmap step (`# %%` cells, run interactively in VS Code/Jupyter)
- `data/`        : prompt sets
- `results/`     : small outputs (plots, CSVs). Large tensors are git-ignored.
- `research_log.md` : what we did, predicted, observed, learned, step by step
